# Plan 001 — MVP

## Goal

A responsive web app where a couple can register spends and income, organize them by category with budgets, track card due dates, split shared expenses, and settle up — with a dashboard summarizing the current month.

## Decisions this plan relies on

See `docs/decisions.md` D1–D10 (stack, cents, household model, label-only payment methods, monthly budgets, magic links, splits + settlements, card due-date formula, plan versioning, commit conventions).

## Functional spec (condensed)

- **Categories**: name + color. Clickable from dashboard → entry list per category.
- **Budgets**: one monthly amount per category (e.g. Renta $9,000.00 MXN), repeats every month.
- **Payment methods**: `cash` or `card`; cards carry a label ("TDC Revolut"), `cut_day`, `due_day` (1–31, repeat monthly). No card numbers.
- **Transactions**:
  - *Spend*: amount (MXN default, multi-currency ready), date (datepicker, defaults to today, dd/mm/yyyy), description, category, payment method, optional split (`is_shared` + payer %).
  - *Income*: amount, date, description, source (single default source; schema supports many).
  - Card spend shows live: `day(date) < cut_day` → "Se paga el {due_day} de {este mes}", else next month.
- **Dashboard**: current-month totals (`- $00,000.00 MXN` / `+ $00,000.00 MXN`), 6-month income-vs-spending bar chart, collapsible budget progress sorted most-full → least-full, registry grouped by month (description, amount, payment method).
- **Balance**: who owes whom from shared expenses; record settlements ("saldar").

## Out of scope (v1)

Multiple households per user, month-specific budget overrides, recurring transactions, receipt uploads, PWA/offline, full multi-currency conversion. See `docs/known-limitations.md`.
